行业观察

旅行 Agent 不是 OTA 的终局

OTA 的消费者界面已经接近稳定终局。AI 真正改变的，是后台的成本与履约，不是用户为什么打开 OTA——这是经过现实检验之后的判断。

先看今天 OTA 的核心页面：

输入目的地和日期 → 展示几百家酒店 → 筛选排序 → 用户选择。

下一代可能变成：

用户说需求 → AI 理解约束 → 生成方案 → 自动组合采购 → 行中调整 → 售后处理。


用户不再"使用 Booking 搜酒店"，而是把一次旅行目标交给它。

这个判断听起来顺理成章。但现实检验之后，我发现它只对了一半。

第一版判断：OTA 会变成 AI 驱动的交易与履约网络
一、最先消失的是"货架式搜索"

现在 Booking、Expedia 很大一部分产品价值，来自：

聚合酒店、展示价格、评论和图片、排序筛选、帮助用户完成预订。

但这些信息非常适合被大模型重新组织。


未来用户可能直接说：

10月带父母去日本七天，不要频繁换酒店，酒店离地铁近，预算3万元，避开游客特别多的地方。


Agent 会自己完成：

理解家庭成员和隐性要求；比较目的地、航班、酒店；读取取消政策；平衡价格、位置和舒适度；生成三套完整方案；获得授权后直接预订。


所以，搜索框、筛选器、列表页不会完全消失，但会从主入口退化为辅助工具。

OTA 辛苦积累二十年的"搜索与排序产品"，会被压缩到一次 Agent 调用里。

二、平台真正的下一步是"旅行执行 Agent"

今天的 AI Trip Planner，大部分还是"会聊天的搜索框"。真正的变化不是生成行程，而是拥有执行能力。


一个完整的旅行 Agent 应当连续完成：

理解需求；生成方案；检查实时库存和价格；预订机票、酒店、用车和门票；处理支付、身份和权益；监控航变、天气与签证风险；自动改签、取消和索赔；旅行结束后处理发票与报销。


这时，旅行订单不再是一次交易，而是一个持续运行十几天甚至几个月的任务。

Booking 已经把方向明确称为 Connected Trip：把住宿、航班、地面交通、景点、支付连接起来，并将 AI 放在这一愿景的中心（Booking Holdings 投资者介绍）。


但要注意："Connected Trip"原来是交叉销售逻辑，AI 时代会把它升级成持续执行逻辑。

以前是订完酒店，再推销机票。

未来是 Agent 持有整个旅行目标，根据变化重新安排所有环节。

三、前台可能被别人拿走，后台反而更加重要

Booking、Expedia 最大的危险，并不是另一家 OTA，而是：

ChatGPT；Google Gemini；Apple/Siri；航空公司和酒店自己的 Agent；银行、信用卡和会员体系；抖音、小红书等内容入口。

用户可能在这些入口完成决策，不再打开 OTA App。

Google 已经把旅行规划、航班酒店信息和预订合作伙伴放进 AI 体验中，合作方包括 Booking、Expedia、Marriott 等（The Verge）。


这意味着未来可能发生一个重要分层：

层次 谁可能掌握 核心价值
用户入口 ChatGPT、Google、抖音、OTA Agent 理解用户、生成方案
决策与编排 旅行 Agent 跨品类组合、动态决策
交易网络 Booking、Expedia、航旅平台 库存、价格、预订、支付
履约与风险 OTA、供应商、保险机构 改签、退款、兜底、赔付
实际供给 酒店、航司、景区 提供服务

因此，Booking 和 Expedia 可能变得有点像旅游业的"支付宝＋AWS＋交易所"：

消费者未必知道订单由谁提供；但库存查询、价格确认、支付和售后仍经过它。

平台从显性的流量品牌，变成隐性的交易基础设施。

界面可能被去中介化，履约却很难被去中介化。

四、Booking 和 Expedia 可能走向不同终局

Booking：全球消费者旅行 Agent

Booking 更可能继续强化：Booking.com 品牌；Genius 会员；全球酒店供给；支付能力；Connected Trip；直接面向消费者的个人旅行 Agent。

它希望掌握从需求产生到旅行结束的整个用户关系。


其最终形态可能是：

一个知道你过去住过什么酒店、预算多少、喜欢什么位置，并可以替你完成全部交易的全球旅行管家。

Booking 的优势是酒店供给密度、转化数据和跨国交易能力。

弱点是机票、内容灵感和用户日常入口并不占绝对优势。


Expedia：旅游行业的交易基础设施

Expedia 很可能越来越偏向双重结构：

前台继续经营 Expedia、Hotels.com、Vrbo；后台成为银行、航空公司、零售平台和其他 Agent 的旅游供应商。

这个方向已经很明显。2025年第四季度，Expedia B2B 总预订额增长24%，明显高于B2C的5%（Expedia 2025年业绩）。


Expedia 的未来可能更像：

任何公司要在自己的 App 或 Agent 里卖酒店，都可以调用 Expedia 的库存、定价、支付和客服能力。

也就是说，Booking 更想成为"旅行领域的超级 Agent"，Expedia 更有可能成为"所有旅行 Agent 背后的平台"。

五、真正的护城河也会改变

过去 OTA 的护城河主要是：

流量；SEO和广告投放能力；酒店数量；评论数量；App品牌；用户搜索和转化数据。


下一阶段会变成：

1. 可执行的供给网络

不只是"我知道这家酒店多少钱"，而是：价格是否真实；能否立即确认；是否支持变更；退款规则能否机器执行；出问题谁承担损失。

静态信息很容易被 AI 获取，可靠执行权很难复制。


2. 跨供应商履约能力

一次旅行可能涉及五六个供应商。

航班取消以后，Agent 是否能同时：延后接机；修改酒店入住；调整门票；重新计算总成本；判断由谁赔偿。

这里不是简单的 LLM 问题，而是复杂的权限、规则、资金和责任问题。


3. 支付与信用

未来 Agent 自动交易，需要平台提供：用户授权额度；虚拟卡；多币种结算；延迟付款；价格保障；退款垫付；欺诈识别。

OTA 会越来越像金融机构。


4. 真实结果数据

未来最有价值的不是用户点击了哪家酒店，而是：用户最终是否满意；什么推荐导致取消；哪类酒店实际投诉率高；什么情况下应该贵一点但更可靠；哪个供应商在航变时真正配合。

这是"决策—执行—结果"的闭环数据，也是通用 AI 入口短时间内不容易获得的。

六、商业模式会从"流量抽佣"变成多层收费

未来收入结构可能包括：

交易佣金；Agent成交服务费；支付和汇兑收入；保险与价格保障；供应商软件费；B2B API费用；售后履约费；广告和推荐费。


但广告业务会受到挑战。

今天酒店可以花钱买排序；未来 Agent 理论上应该为用户寻找最优方案。如果平台一边代表用户，一边收供应商竞价费用，会出现明显的利益冲突。


所以未来会分出两种 Agent：

卖方 Agent：帮助平台和酒店成交，靠佣金赚钱。

买方 Agent：真正代表用户，可能由用户、会员或信用卡机构付费。

这可能成为未来旅行平台最大的制度性矛盾。

七、最终不会是"一家公司吃掉全部"

更可能形成三类公司：

第一类：拥有用户的旅行 Agent——负责理解需求、记忆偏好和做决策。可能是 Booking，也可能是 ChatGPT、Google、抖音或者银行。

第二类：拥有交易网络的平台——负责供给、价格、支付、预订和售后。Booking、Expedia、携程在这里仍然很强。

第三类：拥有独特供给的经营者——大型酒店集团、航空公司、邮轮、景区继续掌握实际产品，并通过多个 Agent 分销。


所以 OTA 不会简单被 AI 消灭，而是会被拆成两部分：

上层的用户决策权，和下层的交易履约权。

它们现在同时拥有两者；未来最大的风险是失去第一部分，只剩第二部分。

对去哪儿更直接的启示

对去哪儿来说，不能只做一个"能聊天、能推荐"的旅行助手。那层能力很快会成为标配，也很容易被通用模型替代。

真正该建设的是三层：

上层：用户 Agent——理解"便宜但不能太折腾"这样的真实偏好。

中层：交易编排系统——跨机票、酒店、火车、用车进行组合和动态调整。

底层：履约网络——价格可信、订单可执行、异常可处理、责任可承担。


去哪儿最值得利用的，不只是低价，而是把低价升级成：

Agent 能够理解和执行的结构化低价。

例如，它不只是找到最低票价，而是知道：便宜200元但要凌晨出发，用户是否接受；分开出票的风险是什么；行李费加进去以后是否还便宜；航变以后谁负责；这次节省的钱值不值得增加失败概率。

这恰好把"结构化低价"和旅行 Agent 连在了一起。

最后我的核心判断是：

OTA 1.0卖库存，OTA 2.0卖比较和流量，OTA 3.0卖完整交易，下一代平台卖的是"替用户承担一次旅行的决策与履约责任"。

谁只是生成答案，谁就会成为薄薄的一层功能；谁能够可靠地执行、修改并为结果负责，谁才是下一代平台。

但做了这么久，我发现现实并非如此

好像做了这么久，并非如此。

比如行程规划，我们实际生活中的行程规划基本不是靠理性推荐，而是自己去看非常多的视频和图文，形成兴趣。

再比如订酒店，在 LLM 里订酒店并没有特别的价值：没有 OTA 的基础信息，LLM 无法完成自然语言搜索；反过来说，OTA 也能做相同的事情。

更麻烦的是，多数人订酒店没有那么复杂，几个条件就可以选择了，更多的是选择地段和价格。

LLM 没有足够的用户价值，让用户改变预订习惯。

再往前推一步：修正后的判断

对。再往前推一步，你这个观察实际否定了一个流行前提：

旅游不是"信息不足、决策复杂，所以需要 AI 代替决策"的行业。

很多时候，浏览、比较、想象本身就是消费体验；最后的交易反而很简单。


所以不能因为大模型出现，就倒推出 Booking、Expedia 下一步必然是"旅行 Agent"。

更可能的答案是：OTA 的消费者产品已经相当接近稳定形态，未来主要不是产品形态革命，而是平台经营深化。

一、行程规划本来就不是一个标准优化问题

AI行程规划假设用户的需求是：我有一组明确偏好，请替我求出最优旅行方案。

但现实更像：我还不知道自己想去哪儿，通过不断看内容，逐渐形成兴趣。


这个过程有几个特点：

偏好不是预先存在的，而是在浏览中生成；用户喜欢偶然发现，而不是只看"最适合自己"的结果；图片和视频提供的是氛围感，文字总结无法替代；用户经常不是在完成任务，而是在消遣和想象；决策过程可能持续几周，并不追求效率最大化。


所以"看了100条视频才决定去北海道"，不能被视为低效率。那100条视频本身就是旅行体验的前半段。

LLM可以总结"北海道适合什么人"，却很难制造某个雪景视频带来的欲望。

旅游首先是欲望生成，之后才是理性选择。

二、酒店预订已经被OTA压缩得足够简单

大多数酒店预订实际上是一个非常浅的决策漏斗：

去哪里；住哪个地段；大约多少钱；评分是否过关；看图片和差评；下单。

OTA现有的地图、价格、评分和筛选器，已经非常适合这个任务。


假设用户说：

帮我找东京交通方便、安静、适合带父母、每晚1500元以内的酒店。

LLM表面上理解了需求，但真正产生结果仍然依赖OTA拥有的数据：

用户表达 实际需要的底层数据
交通方便 酒店坐标、地铁站、线路和距离
安静 房型、临街情况、评论语义
适合父母 电梯、步行坡度、房间面积、早餐
1500元以内 实时库存、税费和汇率
值得住 评分、差评、价格和取消政策

LLM没有这些数据，就只能说一些看似合理但无法交易的话。

OTA有了这些数据，接一个通用模型便能做同样的自然语言解析。

因此：大模型不掌握供给，OTA又不缺大模型。

自然语言酒店搜索很难成为ChatGPT相对OTA的结构性优势。

三、自然语言也没有明显战胜现有界面

对简单、明确、频繁修改的条件，点击往往比对话高效。

用户通过地图一眼就能看见：酒店在哪儿；周围有什么；贵多少；还有哪些选择；改一下价格区间会发生什么。

而对话界面每次只展示少量答案，会损失空间关系、价格分布和选择控制感。


尤其旅游属于低频、高金额、容易后悔的消费。用户通常不愿意只接受Agent给出的三个答案，而是仍想确认：

有没有漏掉更便宜的；隔壁街区怎么样；为什么不推荐这一家；这张照片真实吗。


所以合理形态不是"对话替代列表"，而是：

AI帮助用户设置条件、解释差异，地图和列表继续承担最终选择。

这只是搜索体验的一项改进，不足以改变预订习惯。

四、过去几年旅行规划产品没有起飞，不只是技术不够

如果问题只是模型能力不足，那么随着模型进步，用户使用应该明显增加。但旅行规划类产品长期面临的是更基础的问题：


使用频率太低：多数用户一年只有几次复杂旅行，没有动力学习和养成一个新的Agent入口。

错误成本太高：餐厅推荐错了损失有限，酒店日期、位置、房型、签证或者退改规则错了，损失可能很大。

结果难以验证：Agent声称这是"最适合你的酒店"，用户无法确定它搜索了多少库存、是否受佣金影响、有没有漏掉促销。

交易仍需人工确认：只要用户还要核对日期、价格、房型、行李和取消政策，Agent节省的操作就很有限。

选择本身具有愉悦感：不少人愿意花时间看酒店、攻略和视频，并不希望被完全自动化。


所以旅行Agent没有大规模普及，并非再等一次模型升级就会自然解决，而是消费者价值本身可能没有想象中大。

五、由此得出的重要结论：OTA可能已经接近消费者产品的"稳定终局"

Booking、Expedia并不一定需要变成一个全新的物种。

类似超市、电商、搜索引擎，基本交互可以保持二十年：搜索—筛选—比较—购买。

它们下一步更像经营进化，而不是界面革命：


1. 从单次交易转向会员经营

用会员价、积分、跨品类权益和售后保障，降低用户每次重新比价的意愿。

本质是把"哪里便宜就去哪里买"变成"差不多就继续在这个平台买"。


2. 从酒店佣金扩展到旅游零售利润

增加：机票、租车、接送和门票；保险和价格保障；支付、汇兑和分期；广告和商家推广；企业差旅和B2B分销。

增长不一定来自新的消费者界面，而来自一位用户、一笔旅行产生更多收入。


3. 从流量平台转向供应链控制

加强：独家价格；会员库存；实时确认；支付结算；商家运营工具；退款与赔付能力。

消费者仍然看到相似的酒店列表，但平台对交易的控制更深。


4. 从B2C品牌转向旅游基础设施

特别是Expedia，可以把库存、预订、支付和售后提供给银行、航空公司、会员平台以及未来的AI入口。

即使用户从ChatGPT开始，最后调用的仍可能是Expedia的供给。


5. 用AI降低内部成本

AI更确定的价值发生在用户看不见的地方：自动处理退改和航变；客服自动化；评论总结与违规识别；酒店信息维护；商家服务；营销素材生产；软件开发和内部运营。

这会改善利润率，但不会创造一种全新的OTA。

六、真正可能改变OTA的不是LLM，而是"兴趣平台能否闭环交易"

抖音、小红书、YouTube对OTA的威胁比通用LLM更大，因为它们参与了需求形成。

但内容平台也有自己的结构性问题：

从种草到出行可能间隔数月；用户看内容时未必有明确日期和预算；酒店是标准商品，最终仍会跨平台比价；复杂售后与平台内容体验完全不同；交易需要库存、支付、客服和供应商治理。


所以最可能出现的不是内容平台全面取代OTA，而是重新分工：

内容平台制造兴趣并获得广告收入；OTA承接搜索、价格比较、交易与履约。

部分流量入口会迁移，但OTA的交易层仍然稳定。

七、对去哪儿的战略含义也要相应收缩

不应该把"旅行Agent"当成一个新的主航道。它更适合作为若干局部能力。

场景 AI价值 是否改变入口
行程灵感生成 有一点 很难
酒店自然语言搜索 有一点 很难
评论与差评总结 明确 不改变
低价差异解释 明确 不改变
退改、航变和投诉 很高 可能形成服务入口
客服与商家运营 很高 属于后台革命
多人多程复杂出行 较高 小众场景
普通酒店预订 很低 基本不改变

内容平台种草后，如何让用户更自然地进入去哪儿完成比较；

如何继续强化地段、价格、时间和风险的选择效率；

如何用AI大幅降低交易后的履约成本。

我的修正结论是：

Booking、Expedia下一步未必是"变成什么"，而是继续成为更深、更赚钱、更自动化的OTA。

前台仍然是地图、图片、价格和列表；后台逐渐变成高度自动化的供给、支付、广告和履约系统。

AI在这里大概率是一项类似移动化、云计算和推荐算法的基础技术：会改变成本和局部体验，却未必改变用户为什么打开OTA、怎样挑酒店以及最终为何下单。
