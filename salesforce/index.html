InsightView · AI Agent 是否会颠覆 Salesforce

📌 核心观点
推 1 · 核心结论

AI Agent 不会"替代"Salesforce，但正在颠覆其商业模式——从按人头收费的 SaaS 订阅制，转向按结果付费的数字劳动力平台。

Salesforce 的生死不在于 CRM 是否被淘汰，而在于能否在 Agent 时代重新定义自己的价值层：是继续做"人用的工具"，还是转型为"Agent 运行的平台"。

Benioff 的判断是："自我颠覆好过被别人颠覆"。Agentforce 就是这把刀——它既切向竞争对手，也切向自己的旧模式。

推 2 · 一句话判断

3-5 年内，AI Agent 不会消灭 Salesforce，但会压缩其 per-seat 收入增速 30-50%。

Salesforce 的数据护城河、客户基数和 Agentforce 先发优势，使其大概率成为 Agent 时代的"系统之系统"——但估值逻辑将从"人头税"切换为"任务税"。

🏢 主题简介
推 3 · SaaSpocalypse：2 万亿美元蒸发

2026 年 2 月 3 日，被华尔街称为"Black Tuesday for Software"。S&P 500 软件指数单日暴跌 13%，创历史最大单日跌幅。

48 小时内约 $285B 市值蒸发，六周内 damage 扩大到$2 万亿。Salesforce 从高点跌约 38%，HubSpot 跌 51%，ServiceNow 跌 36%。

导火索不是财报暴雷——是 Anthropic 发布 Claude Cowork 和 OpenAI 发布 Frontier 平台后，市场第一次"看见"AI Agent 可以替代整个 SaaS 品类的人类操作者。

推 4 · 核心矛盾：Agent 不需要"席位"

SaaS 二十年的增长引擎是一个极简公式：更多员工 = 更多软件席位 = 更多订阅收入。Salesforce 靠这个模型做到了 $41.5B 年收入。

但 AI Agent 不登录系统、不点菜单、不产生席位费——它直接调 API 完成工作。一个 Agent 可替代 10-15 个中层员工的管理工作量。

Gartner 预测：2025 年仅 <5% 的企业应用内置 AI Agent，到 2026 年底将达40%。席位压缩不再是假设，而是正在发生的财报数字。

📦 公司战略
推 5 · 战略转向：从 CRM 到"数字劳动力平台"

Benioff 在 Dreamforce 2025 上宣布："Salesforce 不再是一家 CRM 公司，而是一家 AI Agent 公司"。这是公司 27 年历史上最激进的身份重构。

核心逻辑：CRM 是"记录系统"（System of Record），Agentforce 要做"行动系统"（System of Action）。不再帮人管理数据，而是让 Agent 直接执行业务。

这不是防御性转型，是进攻性扩张——Benioff 明确表示 Agentforce 将进入 ITSM 领域，直接对标 ServiceNow。

推 6 · 定价模式革命：从 per-seat 到 AWU

Salesforce 推出Agentic Work Units (AWU) 作为核心计费单位：每次 Agent 自主完成任务计为一个 AWU，标准对话 $2/次，自主操作 $0.10/次。

这直接承认了席位制无法存活——但也是一个精算赌注：Salesforce 赌自己能拥有 Agent 层，而不是被绕过。

截至 FY2026 Q1，Agentforce ARR 达 $12 亿（同比增长 205%），签署 29,000 份协议，交付 24 亿 AWU。新合同中超半数来自存量客户追加。

推 7 · 竞争格局：嵌入式 vs 覆盖式

Agent 时代的主战场是一条战略断层线：Agent 应该活在系统之内，还是系统之上？

Salesforce 和 ServiceNow 押注"嵌入式"——Agent 深度绑定自有数据和工作流，控制力强但锁定客户。OpenAI 和 Anthropic 押注"覆盖式"——Agent 坐在所有系统之上，用 MCP 等开放标准连接，灵活但数据控制弱。

两种路径各有合理性，大型企业被迫同时评估。但 Salesforce 的优势在于：CRM 原生数据访问权——Agent 不需要重新接入数据源，因为它本身就长在数据上。

推 8 · AI-native 挑战者：Rox AI、11x.ai、Coffee

真正的威胁不是 OpenAI 或 Anthropic，而是AI-native 原生创业公司——它们从第一天就按 Agent 架构设计，没有 25 年的历史包袱。

Rox AI（红杉领投 $5000 万）直接杀入 CRM 腹地：员工下达线索和运营要求，Agent 端到端执行从数据分析到邮件发送的全流程，不需要人类操作 CRM 界面。

11x.ai 的 Alice 和 Artisan 的 Ava 已能 24/7 自主完成 SDR 全流程。Coffee 则以"AI-first CRM"定位，自动从邮件/日历/通话中捕获数据，消除 64% 的手工录入时间。

🧩 产品战略
推 9 · Agentforce 产品演化 Timeline

从被嘲笑的"Clippy 2.0"到 $12 亿 ARR 的数字劳动力平台，Salesforce 用 18 个月完成了三次产品范式跳跃。

推 10 · Atlas Reasoning Engine：核心技术差异化

Agentforce 2.0 的核心是Atlas Reasoning Engine——专为商业决策设计的推理引擎，不是通用 LLM 的简单封装。

Atlas 运行四步流程：上下文组装 → 计划生成 → 护栏评估 → 执行监控。在商业决策基准测试上达到96% 准确率，通用模型未微调时仅 78%。

关键差异：Atlas 在执行前会检查业务规则（消费限额、折扣阈值、数据访问策略、合规要求），这是纯 LLM Agent 无法做到的企业级护栏。

推 11 · Headless 360：从 UI 到 API 的架构转向

2026 年 4 月 TDX 大会上，Salesforce 发布Headless 360——将核心 CRM 能力暴露为 API、CLI 和 MCP 工具，Agent 可以不经过传统 UI 直接操作。

这标志着 Salesforce 承认了一个事实：Agent 时代的用户不是人，是 Agent。传统 CRM 的仪表盘和菜单对 Agent 毫无意义。

同步推出 Agentforce Vibes 2.0 云端 IDE，100+ 工具和技能随 Headless 360 一起上线。这是一次从"给人看的 PaaS"到"给 Agent 看的语义层"的根本转向。

推 12 · 数据护城河：Data Cloud + Informatica

Salesforce 最大的防御性资产不是 Agentforce 本身，而是Data Cloud——统一了跨产品线的客户数据池，创造了纯 AI 创业公司难以复制的网络效应。

2025 年 11 月以 $80 亿收购 Informatica，补齐数据治理和 MDM 能力，确保 Agent 工作在可信、合规的数据之上。

44% 的组织将数据质量列为 AI 应用最大障碍。Salesforce 的赌注是：谁掌握最干净的企业数据，谁的 Agent 就最可靠——这比模型能力本身更难被颠覆。

🏗️ 组织文化
推 13 · Benioff 的自我颠覆：停招工程师，砍客服团队

Benioff 宣布 2026 财年不再招聘新工程师——AI 工具已为开发工作带来 30%+ 效率提升。客户支持团队从 9,000 人缩减至 5,000 人。

这不是裁员公告，是战略信号：公司在用 Agent 替代自己的员工，然后再把这个能力卖给客户。Benioff 在达沃斯说："从现在起，我们管理的不仅是人类员工，还有数字员工。"

同时招募 1,000 名应届生和实习生建设 AI 平台——砍掉旧岗位、建新岗位，用组织层面的自我清洗证明 Agent 战略不是 PPT。

推 14 · 内部 AI 应用：30-50% 工作已由 Agent 完成

Salesforce 内部 30-50% 的工作已由 AI Agent 承担，2026 年预计在 Anthropic token 上花费$3 亿，主要用于编程 Agent。

$250 亿加速回购 + $500 亿回购授权 + 季度股息上调 5.8%——Benioff 用金融工程向市场传递信心，但自由现金流增速预期从 9-10%腰斩至 4-5%。

矛盾信号：一边大举发债回购撑股价，一边砍人押注 Agent。市场读到的信息是：管理层相信 Agent 是未来，但过渡期的阵痛已经到来。

推 15 · 客户落地的真实差距

Williams-Sonoma 的 AI 助手 Olive 预期自主解决 60%+ 聊天咨询——但部分标杆案例（如 SharkNinja）被指仍在"开发中"，而非已交付成果。

Salesforce 客户满意度 2025 年下降超 15%。Gartner 报告显示一线员工对 AI 工具支持率仅 30%，AI 功能多数时间处于"沉睡"状态。

核心问题：Agentforce 的 AI 功能多为独立模块，需搭配至少5 个周边应用才能发挥完整功能，部署门槛远高于 Benioff 宣称的"简单易行"。

🎯 核心结论：三维度归因
推 16 · 战略维度：自我颠覆 vs 被颠覆

Salesforce 选择了最难但最正确的路——主动摧毁自己的 per-seat 模式，用 AWU 消费制定价替代。Benioff 清楚：不自我颠覆，就会被 AI-native 创业公司颠覆。

但风险在于：Agentforce 消费收入能否跑赢席位收入下滑？FY2026 总营收增速已降至 10%（几年前是 25%），AI 相关收入占比仍不足 7%。

Bernstein 的看空逻辑：Agent 市场会比 Salesforce 假设的更快商品化。如果 $2/对话的价格持续下探，AWU 模型本身也撑不住高估值。

推 17 · 产品维度：数据护城河 vs 架构劣势

正方：Salesforce 拥有 150,000+ 企业客户、$41.5B 年收入基盘、Data Cloud 统一数据层、Informatica 数据治理能力——这些是AI-native 创业公司无法速成的基础设施。

反方：Salesforce 背着 25 年的历史架构包袱。AI 功能是"螺栓固定"而非"原生设计"，数据需要 3-6 个月清洗才能让 Agent 正常工作。Coffee 等 AI-first CRM 从第一天就按 Agent 架构构建，消除 64% 手工录入无需部署周期。

关键变量：Headless 360 能否真正把旧架构"翻转"为 Agent 原生——这决定了 Salesforce 是"有数据的旧平台"还是"Agent 时代的数据基础设施"。

推 18 · 组织维度：Benioff 的决心与执行力

Benioff 是这场转型中最关键的变量。他的优势是敢于做痛苦决策（停招工程师、砍客服），并且有说服市场和企业客户的能力——"数字劳动力"的叙事已经改变了行业话语体系。

但执行力存在裂缝：内部多 Agent 编排功能被前工程总监描述为"永远还有六个月"。2023-2024 年裁员导致的知识断层尚未恢复，AI 人才重招进度跟不上产品路线图承诺。

EU AI Act 合规缺口、高 volume 客户的消费账单超预期、与 non-Salesforce ERP 的集成成本——这些执行层面的摩擦可能比战略方向本身更致命。

🎙️ 补充视角：YouTube / 播客深度访谈
推 19 · Bret Taylor：Agent 是企业软件的新原子单位

Salesforce 前联席 CEO、OpenAI 董事会主席、Sierra 创始人 Bret Taylor 在 Pigment 播客和 Lenny's Podcast 中提出："Agent 是企业软件的新原子单位"，就像网站定义了互联网时代、App 定义了移动时代。

他的核心判断：未来的 Agent 不会是通用型工具，而是垂直领域的深度专家。大多数 SaaS 会被替代——不是被一个超级 Agent，而是被一群垂直 Agent 分别吃掉不同业务环节。

对 Salesforce 而言这是双刃剑：Bret 知道 Salesforce 的弱点在哪——他是前 CEO。但他也认为掌握企业核心数据的平台不会消亡，"数据在哪，Agent 的价值就在哪"。

推 20 · "按结果付费" vs "按席位付费"：定价范式之争

Bret Taylor 在 Sierra 实践中提出 RaaS（Result as a Service）模式——客户不为软件许可付费，而是为 Agent 完成的业务结果付费。他直言"按 token 计费大错特错"，因为客户不关心你消耗了多少算力，只关心结果。

这与 Salesforce 的 AWU 模式形成有趣对照：AWU 仍是"按动作计费"（$2/对话、$0.10/操作），而 Bret 主张的是"按业务成果计费"（解决了客户问题才收钱）。

Sierra 的一条客户消息背后可能调用 20+ 次推理请求、多个不同模型——但客户只看到结果。Bret 认为模型会像数据库一样商品化，真正的差异化在业务流程而非技术栈。

推 21 · Sam Altman 的"SaaS 已死"预言

OpenAI CEO Sam Altman 在 TBPN 和与 Vinod Khosla 的对话中多次预言："SaaS 已死，服务即软件到来"。核心逻辑是——如果任何软件都可以即时生成，你不再需要"购买"某家 SaaS 公司的产品。

Altman 的判断更激进：Agent 不需要官方 API 就能接入任何服务，"每家公司现在都是 API 公司，不管它愿不愿意"。Agent 会自己写代码访问服务，传统 UI 彻底失去价值。

但他也划了一条线：拥有强核心系统并用 AI 做战略升级的在位者最有可能存活，只有"薄封装层"的 SaaS 会死。Salesforce 属于哪一类，取决于 Headless 360 转型的速度。

推 22 · 反方观点：Agent 杀不死有数据的 SaaS

富途研究指出一个被忽视的逻辑："AI 越能取代工作，Salesforce 就越有价值"——因为 Agent 需要数据才能工作，而 Salesforce 掌握着 Agent 无法绕过的业务数据和流程上下文。

Benioff 在分析师电话会上直言："我们已把 Salesforce 重建成了 Agentic Enterprise 的操作系统"。Agentforce + Data 360 合并 ARR 超 $29 亿，同比增长 200%+——这不是防御，是加速。

关键区分：SaaS 世界被切成两半。没有独家数据的"薄封装工具"（Gainsight、Outreach、Gong）面临真威胁；但深度嵌入核心业务流程、掌握不可替代专有数据的平台，反而因 Agent 的存在而增值。

推 23 · Agent 绕过 UI：SaaS 从"主入口"沦为"后端存储"

更深一层的恐慌来自 TechFlow 的分析：传统 SaaS 的商业前提是"软件是给人用的"——Salesforce 设计 UI、仪表盘、工作流，本质是培养用户习惯、提高粘性。

但 Agent 不需要 UI。当销售员直接打开 Claude 完成工作，Claude 通过 API 读写 Salesforce 数据——Salesforce 从企业工作流的主入口，沦为数据存储的后端。这是降维打击。

Salesforce 的反击是 Headless 360——主动暴露 API/MCP 工具层，试图从"被绕过的 UI"变成"Agent 的语义层"。这是被迫的架构转向，但也是抢回控制权的唯一路径。

推 24 · DIY Agent 的失败率：平台 vs 自建的差距

Salesforce+ 官方节目引用研究数据揭示了一个关键事实：企业自建 AI Agent 的平均准确率仅 52%——大多数 DIY 项目永远停留在试点阶段，无法达到生产级精度。

而使用 Agentforce 平台的客户，平均准确率提升至75%+，部署速度比 DIY 快16 倍。核心差距在于推理层、数据集成、护栏安全和持续维护。

这为 Salesforce 的护城河提供了新论据：Agent 不是"能跑就行"，企业级精度需要深度业务上下文和持续调优——这正是平台型产品的价值所在。但也可能只是阶段性的优势，随着底层模型能力提升，DIY 与平台的差距会收窄。

推 25 · 三条护城河同时被 AI 拆解

头条分析指出，SaaS 过去二十年的三条护城河正在被 AI 逐一拆解：

① 网络效应：当 AI 能自建适配业务的 CRM，标准化生态（AppExchange）价值在下降——你的"生态"就是你的业务本身。

② 数据壁垒：AI 编程工具可直接对接旧系统 API，自动清洗、字段映射、迁移数据——两个月搞定的迁移，数据壁垒不再成立。

③ 迁移成本：以前自建 CRM 需要五六人干半年，现在两人两月+AI 工具——成本降到十分之一。"自建"与"购买"的交叉点已经到来。

推 26 · Benioff 的反泡沫论："太快了"

在 Equity Podcast 和多场访谈中，Benioff 反复强调一个词："too soon"——技术能力的跃迁和商业模式的瓦解之间，往往隔着好几年。

他用 Verizon 裁员 1.3 万人的案例做反证：裁员不自动等于"AI 接管"。Verizon 股价长期横盘，说明问题在于传统电信行业的增长困境，而非被 AI 颠覆。

Benioff 的核心逻辑：企业迁移系统的成本、合规风险、组织惰性，远比模型能力的进步慢得多。"SaaS 不会一夜消失，Agent 也不会一年内接管企业世界"——方向可能是对的，但节奏几乎一定被高估了。

推 27 · "Service as a Software"：商业模式的根本翻转

Altman 和 Bret Taylor 不约而同指向同一个概念：从"Software as a Service"到"Service as a Software"——AI 不再是帮人构建软件的工具，而是直接提供完整的服务结果。

经济现实是残酷的：用 AI 仅仅让开发者提速的公司，是在优化一个过时的模型；让 AI 直接担任"开发者"的公司，在一个全新的经济现实中运营。

对 Salesforce 的启示：Agentforce 目前仍是"让 Agent 帮人用 CRM"，而真正的终局可能是"Agent 就是 CRM"——不需要人参与，Agent 直接完成销售、服务、分析的完整闭环。Salesforce 离这个终局还有距离。

推 28 · Benioff（X）：The software bears are dead wrong

2026 年 4 月 20 日，Benioff 在 X 上直接反击做空者，原帖写道："The software bears are dead wrong."

他引用两个客户案例：Pearson 的 Agentforce 将无需人工干预解决的客户问题比例提升 40%；PenFed 用 Agent 处理密码重置和账户解锁，IT 工单总量下降 40%。

结尾造了一个新词："Agenticware, not Software"——这不是修辞，是品牌层面的身份切割。Salesforce 已全面弃用"Cloud"命名（Sales Cloud → Agentforce Sales），Benioff 甚至在内部讨论将整个公司更名为"Agentforce"。

推 29 · Benioff（财报电话会）："SaaSpocalypse 被大脚怪吃掉了"

FY2026 Q4 财报电话会上，Benioff 六次提及"SaaSpocalypse"，语调从嘲讽到不屑：

"你听说过 SaaSpocalypse 吗？这可不是我们第一次经历。如果真的有 SaaSpocalypse，它可能已经被大脚怪吃掉了——因为现在很多公司都在大量使用 SaaS，而且由于 AI 代理的出现，它变得更好用了。"

他特别指出：连 Anthropic 这样的 AI 公司自己"就用很多 SaaS"。同期数据：Salesforce Q4 营收 $112 亿（YoY +12%），全年 $415 亿（YoY +10%），Agentforce ARR 达 $8 亿（YoY +169%），同时宣布 $500 亿回购。这是用真金白银回应市场恐慌。

推 30 · CEO 公开互撕：Benioff vs Nadella 的"Clippy 2.0"

这是 2025-2026 年科技界最公开的 CEO 级口水战。导火索是微软 CEO Nadella 在新德里宣称："我们所知的 SaaS 时代即将结束"，SaaS 本质只是"CR­UD 数据库加业务逻辑"，未来逻辑将迁移到 AI Agent 层。

Benioff 的回击是直接人身级嘲讽——多次在公开场合和 X 上称微软 Copilot 为"Clippy 2.0"："根本不起作用，没有任何准确性"，并称微软是"快速追随者"，"他们肯定会像往常一样想抄袭我们"。

两条技术路线的本质分歧：Nadella 押注"Agent Stack 替代 App Stack"——Agent 成为操作系统级调度层，SaaS 退化为数据库后端；Benioff 押注"Agent 嵌入业务流程"——Agent 深度绑定数据和工作流，不颠覆 SaaS 而是让 SaaS 更关键。微软 16 万 Copilot 客户 vs Salesforce 15 万 Agentforce 客户，战场正在正面碰撞。

推 31 · Satya Nadella（X）："Reverse Information Paradox"

2026 年 7 月 12 日，Nadella 在 X 上发布长文提出"逆向信息悖论"——企业使用 AI 时不只付钱获取智能，还在不经意间交出自己的知识。

他的核心警告：每次员工与 AI 交互——提示词、纠错、评估方法、工作流模式——都在生成"智能废气"（intelligence exhaust），这些被 AI 厂商收集后用于改进模型，而企业反而丧失了差异化知识。

对 Salesforce 的启示：Data Cloud + Informatica 的价值不仅是"数据存储"，更是"知识主权"——企业需要控制自己的 AI 记忆、交互痕迹和反馈系统，而不是把一切交给 OpenAI 或 Anthropic。Nadella 的这番话，间接为 Salesforce 的数据护城河叙事提供了弹药。

推 32 · Aaron Levie（X）："Agents will use software 100X more than people"

Box CEO Aaron Levie 在 2026 年 6 月 21 日的 X 长文中提出了一个反直觉论点："AI Agent 不会杀死企业软件，而是把它变成高吞吐量基础设施"。

他的逻辑：CRM 记录、企业文档、分析系统——这些在人类时代因为"懒得查"而使用率极低的系统，一旦 Agent 可以无摩擦地 7×24 查询，调用量会暴增 100 倍。Levie 自己已将 Salesforce 的 MCP Server 接入 Claude Code，称"现在用 Salesforce 的频率是以前的 5 倍"。

但代价是：传统权限模型为人设计（角色+会话+界面），Agent 时代需要全新的最小权限、操作审批、审计回滚机制。Levie 认为席位定价无法映射到 Agent——软件必须转向消费制定价，甚至让 Agent 自主支付服务费。这与 Salesforce 的 AWU 方向一致。

推 33 · Aaron Levie（X）："为 Agent 构建软件，而不是为人"

2026 年 3 月 8 日，Levie 在 X 发布长文提出更激进的判断："Agent 将成为所有软件的主要用户"——不是预测，而是工程约束。

他改写了 Paul Graham 的名言："Make something agents want." 关键含义：Agent 不参加 Webinar、不看广告、不回应 onboarding 流程。它只使用最容易集成、最适合任务的工具。如果功能只存在于 GUI 中，对 Agent 来说等于不存在。

这对 Salesforce 的直接含义：Headless 360 暴露 API/MCP 工具层的方向完全正确——但速度必须够快。Levie 预期企业最终会为每个员工运行数百甚至数千个 Agent，到那个比例，软件的"用户"几乎全是 Agent，UI 只是给人看的监控面板。

推 34 · 黄仁勋（GTC 2026）："我们在创造劳动力，不是工具"

NVIDIA CEO 黄仁勋在 GTC 2026 主题演讲中定义了 Agent 时代的经济底层："全球 IT 产业 1 万亿美元，全球经济 100 万亿美元——我们面对百倍市场"。

他的核心判断：AI 已从"生成"到"推理"再到"行动"三阶段进化，推理拐点已经到来。Token 成为新的大宗商品，NVIDIA 预计到 2027 年数据中心基础设施需求达$1 万亿。

关于就业，黄仁勋直接反驳"AI 取代工作"论："完全是无稽之谈"。如果每个软件工程师能产生 $9 万亿的生产力，企业会想招更多人，而不是更少。100% 的 NVIDIA 工程师正在使用 Claude Code、Codex 或 Cursor。这对 Salesforce 的信号是：Agent 不是替代人类员工，而是让每个员工的生产力乘以 10——但前提是你有 Agent 平台。

推 35 · Bret Taylor（Sierra）：$158 亿估值的 Agent-native 颠覆者

Bret Taylor 联合创立的 Sierra 在 2026 年 5 月完成 $9.5 亿融资，估值 $158 亿，累计融资超 $10 亿。ARR 在 7 个季度内从 0 到 $1.5 亿——史上增长最快的企业软件之一。

客户覆盖 40%+ 的 Fortune 50，包括 Deliveroo、Discord、Ramp、Rivian、Sonos、Wayfair、Cigna、SiriusXM。一条客户交互背后可能调用 20+ 次推理、15+ 个模型——但客户只看到结果，按结果付费（RaaS）。

2026 年 6 月 Taylor 在 X 上预测："3-4 年内消费者会更偏好使用 AI 电话 Agent 的企业"。7 月又宣布收购长程 Agent 平台 TakeOff。Sierra 的定位是"Agent OS"——不取代 CRM，而是成为连接 CRM、订单、工单系统的自主执行层。如果 Sierra 成功，Salesforce 就从"客户交互主入口"退化为"数据后端"。

推 36 · Sam Altman（Cisco AI Summit）："每家公司现在都是 API 公司"

Altman 在 Cisco AI 峰会上说出了被反复引用的那句话："Every company is an API company now, whether they want to be or not."

核心逻辑：AI Agent 不需要正式 API 就能接入任何服务——通过浏览器自动化、表单填写、屏幕读取，Agent 可以像人类一样操作任何软件。"权限经济"已死——过去 SaaS 靠控制访问入口收过路费，现在 Agent 直接穿墙。

但他划了一条生死线：只有"薄封装层"的 SaaS 会死，拥有强核心系统+专有数据+网络效应的在位者能活。翻译成 Salesforce 的语境：CRM 数据、合规历史、客户基数是"城堡"；仪表盘和菜单是"沙堡"。潮水来了，城堡能活，沙堡会塌。问题是 Salesforce 两者都有——Headless 360 决定了它到底把自己当城堡还是沙堡。

推 37 · Nadella："成功不是活得久，是保持相关"

2025 年 7 月 Nadella 在微软内部备忘录中写了一句话，可以用来概括所有在位者的焦虑："Success is not about longevity. It's about relevance."

他引用的平台定义也值得深思："一个平台的价值，在于所有使用者的经济价值总和超过平台创造者的价值"。如果 AI 只让模型公司赚钱，而不让使用 AI 的企业更富有，这个生态不可持续。

对 Salesforce 的映射：Agentforce 的 AWU 定价必须让客户算得过账——如果一个 AWU $2 但帮客户省了 $20 的人力成本，生态就成立；如果 Agent 的消费账单超出预期（已在高 volume 客户中出现），客户会逃离而非追加。定价模型的可持续性，比 Agent 本身的能力更决定 Salesforce 的生死。
